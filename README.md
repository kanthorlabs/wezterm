#  Wez's Terminal Emulator Configuration 
> Inspired from https://alexplescan.com/posts/2024/08/10/wezterm/

## Usage

- Clone the repo into directory `~/.config/wezterm`
- Install the wezterm (https://wezterm.org)
- Add this line to `~/.zshrc` to show the git repo, branch, and AWS profile in the tab bar:
  `source "$HOME/.config/wezterm/shell/wezterm.zsh"`

## Shortcuts

| Action | Shortcut |
| --- | --- |
| Move tab left | `Cmd+Shift+Left` |
| Move tab right | `Cmd+Shift+Right` |
| Go to tab N (1–8) | `Cmd+N` |
| Go to last tab | `Cmd+9` |
| Go to split on the left / right / above / below | `Ctrl+Shift+Arrow` |
| Split pane side by side (left / right) | `Cmd+D` |
| Split pane stacked (top / bottom) | `Cmd+Shift+D` |
| Close current pane (closes the tab if it is the last pane) | `Cmd+W` |
